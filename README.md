## <img src="https://api.iconify.design/lucide:folder-git-2.svg?color=%233b82f6" height="22" style="vertical-align: -4px;" /> Proyectos Destacados

* **[Oficina Virtual](https://github.com/ManuLazaro/OficinaVirtual):** Solución completa de gestión para centros deportivos y gimnasios. Agiliza la administración de usuarios, entrenadores, horarios y pagos.
  * *Stack:* Java, Spring Boot, Hibernate, Angular.

### 🔷 Ecosistema .NET
* **[Lab Production Systems](https://github.com/ManuLazaro/LabProductionSystems):** Plataforma unificada para laboratorios farmacéuticos que integra operaciones de fabricación (MOM), LIMS, PDM e I+D.
  * *Stack:* .NET, C#, MySQL, HTML5.
* **[Bundle en Español 🚧](https://github.com/ManuLazaro/BandleEspanol):** Juego interactivo inspirado en la aplicación "Bandle", enfocado en adivinar canciones a partir de pistas de audio.
  * *Stack:* .NET, C#.

### 🐍 Python & AI
* **[AI Text Corrector](https://github.com/ManuLazaro/IA-text-corrector-nlp):** Herramienta basada en Python y AWS para el refinamiento de textos automatizado y corrección gramatical mediante PLN.
  * *Stack:* Python, AWS, NLP.

### 📦 Otros Proyectos
* **[Padel Proyecto](https://github.com/ManuLazaro/padel_proyecto):** Aplicación móvil centrada en la reserva de pistas de pádel, optimizando la disponibilidad y la gestión para usuarios y administradores.
  * *Stack:* Dart, Flutter.
* **[Odoo Dev](https://github.com/ManuLazaro/odoo-dev):** Desarrollo de módulos personalizados dentro de la plataforma ERP Odoo para adaptarla a necesidades empresariales específicas.
  * *Stack:* Python, Odoo, XML, PostgreSQL.
